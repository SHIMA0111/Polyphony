# Step 34: Model metadata (token limits + pricing) across gateway/server/web

## Meta
- **Type**: feature
- **Components**: llm-gateway, server, web
- **Wave**: 5 (parallel group — all steps of the same wave can run concurrently)
- **Depends on**: Step 9: Web data layer migration: TanStack Query, RSC prefetch, per-feature API modules; Step 25: Rust: Anthropic provider adapter; Step 26: Rust: Gemini provider adapter; Step 28: Go: gRPC LLM client swap + retry + health
- **Unlocks**: Step 36: Web room settings drawer; Step 50: Server: context summarization with cached summaries; Step 57: E2E regression: realtime AI core — send, model select, context controls, rate limiting
- **Size**: 1 PR (a few hours for one AI agent)

## Context
`phases.md` Phase 8 explicitly calls for "model metadata (token limits, pricing info)" alongside the gRPC swap, and Phase 7 calls for a "rich" model selection UI, but through Phase 1 `ModelInfo` only carries `id`/`name`/`provider`/`owned_by` — there is no context-window size or per-token pricing anywhere in the stack, so the web `ModelSelector` (`web/src/features/messages/components/ModelSelector.tsx`) cannot show useful comparison data and later features (context-window-aware summarization in step 50, room-default model settings in step 36) have nothing to resolve limits against. This step closes that gap end-to-end: Rust domain → REST DTO → Go domain/gateway client/handler DTO → web types/UI, so every consumer downstream of `GET /models` sees the same enriched shape. It is scheduled after steps 25/26 (Anthropic + Gemini adapters must exist so their `models()` implementations get populated in the same PR, avoiding a second pass) and after step 28 (Go's gRPC `LLMClient` implementation must exist so both REST and gRPC paths carry the new fields) and after step 9 (web must already be on the per-feature TanStack Query API module pattern before `ModelSelector` is rewired to live data).

## Goal
`ModelInfo` (and its REST/gRPC DTO equivalents) carries `context_window` (max input+output tokens the model supports) and pricing (`input_price_per_million_tokens` / `output_price_per_million_tokens`, in USD) from the Rust domain model all the way to the web layer. Every provider adapter in `llm-gateway` (OpenAI, Anthropic, Gemini) populates real published values for its hard-coded model catalog. The Go server's `ai.ModelInfo`, its REST DTO (`ModelResponse`), and its gRPC client mapping (from step 28) all carry the same fields unchanged (pure passthrough, no server-side computation). The web `ModelSelector` is wired to the live `GET /models` endpoint (replacing the last hard-coded/mocked model list) via a TanStack Query hook, groups models by provider, and displays each model's context window and price alongside its name.

## Implementation notes
- **Rust field types**: keep Step 19's shape verbatim — `context_window: Option<u32>` (token counts) and `pricing: Option<ModelPricing>` with `f64` per-1M USD prices (fractional cents at scale), matching existing numeric conventions in `llm-gateway/src/domain/model.rs` (`Usage.prompt_tokens: u32`, `CompletionRequest.temperature: Option<f32>`). Pricing is "per million tokens" (not per-token, never per-1k) to avoid float-precision noise and to match how OpenAI/Anthropic/Google publish their price lists. `Option` stays on the wire (`#[serde(skip_serializing_if = "Option::is_none")]` per Step 19) even though every first-party provider populates `Some(...)` after this step — future dynamic-catalog providers may not know their metadata.
- **Rust rustdoc pattern**: follow the existing style in `llm-gateway/src/domain/model.rs` — a doc comment directly above the struct and a `///` line per field, e.g.:
  ```rust
  /// Best-effort pricing metadata for a model, in USD per 1,000,000 tokens.
  #[derive(Debug, Clone)]
  pub struct ModelPricing {
      /// USD price per 1,000,000 input (prompt) tokens.
      pub input_price_per_million_tokens: f64,
      /// USD price per 1,000,000 output (completion) tokens.
      pub output_price_per_million_tokens: f64,
      /// ISO currency code, e.g. "usd".
      pub currency: String,
  }
  ```
